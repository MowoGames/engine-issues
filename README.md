# Mowo Engine Issue Tracker

This repository is the official issue tracker for Mowo Engine. It is used to report bugs, request features, track regressions, and discuss engine-related improvements.

## Purpose

Use this repository to:

- Report bugs and crashes
- Suggest engine features and improvements
- Track regressions across versions and platforms
- Document reproducible issues with steps and logs
- Coordinate work on fixes and roadmap items

## Before You Open an Issue

Please search existing issues before creating a new one to avoid duplicates.

When creating a report, include:

- Clear title describing the problem
- Short summary of the issue
- Steps to reproduce
- Expected vs. actual behavior
- Version or build information
- Operating system and hardware details
- Logs, screenshots, or minimal project files when relevant

## Issue Categories

Use the most relevant label or category for your issue:

- Bug
- Crash
- Performance
- Feature Request
- Documentation
- Regression
- Question
- Build/Packaging

## Issue Template Guidance

A good issue should be specific and actionable. Include enough detail for maintainers to reproduce and diagnose the problem without extra back-and-forth.

Recommended structure:

1. Summary
2. Steps to reproduce
3. Expected result
4. Actual result
5. Environment details
6. Relevant logs or attachments

## Roadmap and Prioritization

Issues may be prioritized based on severity, impact, reproducibility, and project goals. Some requests may be closed as duplicates, out of scope, or deferred until a later milestone.

## Contribution Expectations

We welcome well-documented bug reports and thoughtful feature requests. Please keep reports factual, respectful, and concise. The more precise the issue, the faster it can be reviewed and resolved.

## Security

If you believe you have found a security issue, do not open a public issue. Follow the project’s secure reporting process if one is defined.

## Maintainers

This repository is intended for tracking and triage. Bug fixes, feature work, and implementation details may live in other repositories or development branches depending on the project structure.
